## Highlights

- **Analytics charts across pipeline outputs:** Choose a fixed output partition, the latest completed partition, the latest N partitions, or all completed partitions when refreshing a chart. Existing charts keep their saved source behavior until you change it.
- **Pipeline run actions:** Cancel selected active runs across pipelines. In Standard pipelines, retry a generated dynamic child and the downstream work that depends on it while preserving unaffected siblings.
- **AI Sidekick:** Investigate dependency-related pipeline failures with Fix with AI, review a proposed requirements change before it is applied, and continue chatting while an active turn is running. Chat history, artifacts, and failure messages are easier to use.
- **Find work faster:** Applied filters are visible and removable on pipeline, run, and trigger lists, and persist when you navigate away and return during the same browser session. Custom UTC ranges can be entered directly for run and monitoring views.
- **Workspace navigation and appearance:** Grouped navigation makes dashboard, monitoring, library, and tool destinations easier to find. A System theme follows your device appearance, alongside refreshed light-mode contrast.

## New capabilities

### Analytics charts and data exploration

  * **Select pipeline output partitions for charts:** Keep a chart on one saved partition, follow the latest completed partition, combine the latest N completed partitions, or include all completed partitions. Mage reevaluates dynamic selections when you explicitly refresh a chart or dashboard; reloading the page keeps the saved chart snapshot.
  * **Keep existing charts stable:** Charts already saved retain their source selection until you change it. Partition selection reports missing outputs and safety-limit failures instead of silently charting an incomplete set.
  * **Manage connections from Data Explorer:** Open connection management from the Data Explorer toolbar in a new tab while keeping your exploration page available.

### Pipeline runs and troubleshooting

  * **Cancel only the runs you select:** From the project-wide Pipeline runs page, select Ready or Running runs across pipelines and cancel those runs without cancelling other active runs.
  * **Retry dynamic work precisely:** In Standard pipelines, retry a generated dynamic child and its dependent downstream work while preserving unaffected siblings. Consumers of an affected reduced collection or shared output rerun when they depend on it.
  * **Inspect logs with clearer controls:** Typing filters the logs already displayed; Search or Enter searches matching logs across the full selected time range. Custom UTC ranges require a valid start and end before applying.
  * **Keep results during refresh errors:** If a later logs refresh fails, the last loaded results remain visible with a retry action.

### AI Sidekick

  * **Investigate dependency failures:** When AI Sidekick is enabled, Fix with AI can examine relevant failed-run evidence and suggest a change to `requirements.txt`. Review the proposed diff before an authorized edit; confirmation follows the environment's action policy. Installation, verification, and manual retry remain separate steps.
  * **Continue a conversation during a running turn:** Send a follow-up while Sidekick is busy. Queued messages wait for backend acceptance, with retry handling when the session is temporarily busy.
  * **Navigate and recover chats:** Resize Sidekick without losing artifact controls, see a reason when a turn fails, page through active chat history, keep archived chats archived, and preserve renamed titles during live updates.

### Filters, dates, and navigation

  * **Return to your filtered lists:** Status, tag, type, and other applied filters on Pipelines, Pipeline runs, and Triggers stay in place when you leave and return during the same browser session. A filter band shows active selections and lets you remove individual values or clear them together.
  * **Enter exact UTC ranges:** Type start and end dates and times directly or choose them from the picker in run and monitoring date filters. Incomplete or invalid ranges cannot be applied.
  * **Use grouped navigation:** Find related dashboard destinations through grouped flyouts, with keyboard and responsive layouts supported.
  * **Follow your device theme:** Choose System, Light, or Dark from the account menu or personalization settings. System follows browser or operating-system appearance changes; explicit selections persist after reload.

## Improvements

  * **Dashboard charts:** Chart refreshes show clearer progress, renamed charts retain the right heading, and date-axis labels are easier to read.
  * **Monitoring focus:** Global Monitoring now emphasizes run health and active runs. Average duration and Duration Trend are no longer shown there; runtime trends remain available on individual pipeline monitoring pages.
  * **Alerts settings:** Edit and save valid alert settings even when another notification channel has a configuration error. Invalid channels are shown in the UI, and a malformed webhook URL does not prevent Email alerts from working.
  * **Workspace access:** Users with workspace-specific roles but no global role can find their assigned workspaces in the management directory under the supported authentication configuration, without gaining workspace-management privileges.
  * **Mage Pro API authentication:** Clusters can opt into service authentication for Mage Pro API requests that have no user identity. The setting is disabled by default; requests with a user identity continue to use user authentication.
  * **Executor memory guard:** Configure the local Python executor's maximum memory-usage threshold for pipeline runs with `MEMORY_USAGE_MAXIMUM`; the default remains 0.95.

---
## Reliability and fixes

  * **Integration setup and execution:** Correct relative-date values in data integration configurations, first-load source templates, and transformer placement in integration pipelines.
  * **Backfill log retention:** Prevent automatic cleanup from deleting logs that still belong to active or recent backfill pipeline runs.
  * **Navigation and sign-in:** Preserve cross-workspace destination paths, OAuth callback query values, and selected workspace roles across navigation. Improve sign-in notice and block-menu contrast.
  * **Filters and editor:** Preserve repeated query values in resource filters, keep Coder file paths and version-history URLs through refreshes, and stabilize template browsing controls.
  * **Account and visual polish:** Improve light-mode colors, filter-menu visibility on small screens, and account controls for pipeline collaborators.
