# Mage Pro Release Notes

**Release ID:** 20260715-1600
**Image tag:** 20260715-1600-py3.12

## Highlights

- **New AI Sidekick:** Brings a more capable in-product AI chat for creating pipelines, debugging failed runs, navigating chat threads, tracking subagent progress, and using Sidekick from editor workflows with more reliable production routing.
- **New Terminal with autocomplete and version control:** Adds terminal autocomplete, Git authentication, reconnect handling, prompt metadata, and production routing hardening.
- **MFA and account security:** Consolidates MFA setup, required sign-in verification, account-settings placement, lockout handling, and migration safety.
- **Monitoring, logs, and observability:** Adds OpenSearch-backed global log search, overview monitoring, pipeline monitoring, schedule heatmaps, and alerting improvements.
- **Pipeline operations:** Improves project-wide retry actions, date filters, trigger search, run links, and run-status workflows.
- **Pipeline authoring and templates:** Expands template browsing and creation, pipeline-file scope, custom syntax themes, dynamic-block output support, and editor polish.
- **Data sources and integrations:** Improves browser-download ingestion, multi-queue Amazon SQS, Salesforce Marketing Cloud SOAP support, Facebook Ads handling, and dbt upgrades.
- **Workspace management:** Improves workspace search, pagination, navigation, release-tag deployments, and configuration editing.

## New capabilities

### New AI Sidekick

  * **Create pipelines with AI chat:** Start AI-assisted pipeline creation from the product and continue iterating in a dedicated Sidekick thread.
  * **Debug failed runs faster:** Open Sidekick from failed pipeline runs and log actions so the chat can start with the relevant execution context.
  * **Use Sidekick from editor workflows:** Bring AI assistance into editing flows without leaving the work surface.
  * **Navigate richer chat history:** Browse, select, archive, restore, and continue Sidekick conversations with clearer thread state and loading behavior.
  * **Track AI work as it happens:** See inline subagent progress and timeline updates while Sidekick works through multi-step tasks.
  * **Use Sidekick in production workspaces:** Route model requests through the correct production API paths and make Sidekick available to editor-role users.

### New Terminal with autocomplete and version control

  * **Autocomplete terminal commands:** Use terminal autocomplete to speed up command entry and reduce context switching while working in Mage.
  * **Work with Git from the terminal:** Authenticate Git operations from the terminal flow and keep version-control actions connected to the active workspace.
  * **Resume terminal sessions more reliably:** Reconnect to terminal sessions with prompt metadata and runtime state preserved more consistently.
  * **Use terminal in production routes:** Run terminal workflows through hardened production routing so browser sessions reach the correct backend paths.

### Security and account access

  * **Support MFA for account security:** Enroll an authenticator app, verify MFA during sign-in, manage MFA from account settings, and track attempt state separately so rollout and lockout handling are safer.
  * **Use stronger OAuth and MCP authentication:** Require real OAuth credentials for local MCP shortcuts and preserve Mage authentication when Cloud handoff is only partially available.
  * **Discover Mage agent capabilities safely:** Query curated Mage tool and resource contracts without exposing broader internal tool registries.
  * **Recover database migration state:** Use `mage db` diagnostic and recovery commands to inspect migration history, schema state, locks, rollback, migrate, or stamp a database.

### Monitoring, logs, and observability

  * **Search logs across the workspace:** Use global log search backed by OpenSearch APIs, curated MCP log-search tooling, and clearer result ordering.
  * **Analyze pipeline health from a consolidated dashboard:** Review recent failures, block reliability, runtime trends, and hot spots from the redesigned monitoring experience.
  * **Inspect trigger load visually:** Use schedule heatmaps to understand trigger load patterns and spot crowded execution windows.
  * **Open logs without blocking the UI:** Fetch remote S3 and GCS logs asynchronously so log inspection stays responsive.
  * **Diagnose Mage agent processes:** Capture MCP lifecycle diagnostics for stdin closure, signals, server exits, uptime, and local activity-log troubleshooting.

### Pipeline authoring, templates, and editor experience

  * **Create pipelines from richer templates:** Browse, preview, and create pipelines from a refreshed template registry and pipeline creation modal.
  * **Focus file browsing on the active pipeline:** Switch the editor file browser between all project files and files scoped to the current pipeline.
  * **Customize code editing appearance:** Apply custom syntax themes and keep code-area theme changes consistent across Monaco, Markdown, and rendered code surfaces.
  * **Use dynamic block outputs more predictably:** Reference dynamic and dynamic-child outputs from dbt SQL blocks with clearer parsing and templating behavior.
  * **Constrain dynamic block fan-out:** Configure guardrails that cap how many dynamic child block runs an expansion can create.
  * **Edit Markdown blocks reliably:** Open Markdown and Documentation blocks directly in the raw code editor from the pipeline editor.

### Pipeline runs, triggers, and operations

  * **See Kubernetes execution phase in run details:** Surface Kubernetes executor lifecycle state directly in block-run tables and logs.
  * **Navigate from workspace runs to execution detail:** Open logs, block runs, pipeline edit, trigger, graph, and failed-run overview pages from workspace pipeline-run links.
  * **Search global triggers:** Filter triggers by trigger name or pipeline UUID from the global Triggers page.
  * **Retry and inspect runs more efficiently:** Use run-status and run-link improvements to move from operational lists into the relevant execution context faster.

### Workspace management

  * **Search and page through workspaces:** Find workspaces from `/manage` more easily while preserving search focus and scroll position.
  * **Deploy from release tags:** Deploy applications from release tags while keeping the existing branch deployment flow available.
  * **Install workspace requirements during deployment:** Install dependencies from a deployed workspace `requirements.txt` as part of the deployment flow.
  * **Manage variables with clearer controls:** Add, search, confirm, and cancel variable edits from a more explicit Variables side-panel flow.
  * **Switch Mage agent clusters:** Use local Mage agent tools to list clusters, inspect the current cluster, and switch active cluster context.
  * **Maintain workspace environments:** Run workspace cleanup commands for cached variables and old logs, and use server-backed user search across email, name, and username.

### Data sources and integrations

  * **Ingest browser-downloaded files:** Use the new `browser_download` source for client-side file download workflows.
  * **Stream from multiple Amazon SQS queues:** Configure Amazon SQS sources to read from multiple queues natively.
  * **Sync Salesforce Marketing Cloud data extensions via SOAP:** Retrieve configured data-extension streams through SOAP-only DataExtensionObject requests.
  * **Preview and sync Facebook Ads data more reliably:** Improve `adcreative` previews, insights pagination handling, and bookmark logging for Facebook Ads sources.
  * **Use dbt 1.11.6:** Run dbt workloads against the upgraded dbt core and aligned adapter pins.
  * **Load integration pages faster:** Fetch integration metadata, docs, and templates on demand so integration pipeline pages do less upfront work.

## Reliability and fixes

  * **Fixed orphaned Codex runner disconnect race:** Fix the Codex runner lifecycle race that could make a normally finishing turn look like an orphaned/disconnected runner.
  * **Fixed Codex goal stream ordering:** Fix Sidekick Goal/Plan streaming so interim assistant messages remain ordered inside Work until the terminal event, while genuine final answers retain final styling.
  * **Fixed imported data loader decorator detection:** Keep Mage's dynamic block decorators visible when block code imports from `mage_ai.data_preparation.decorators`.
  * **Fixed pipeline graph invalid UUID crash and slow dependency parsing:** Fix pipeline graph crashes when malformed pipeline configs contain multiple block entries with `uuid: null`.
  * **Prevented stale migration lock startup deadlocks:** make migration lock acquisition and Alembic execution share the same DB connection explicitly close the setup transaction after taking the advisory lock so startup does not leave an idle-in-transaction lock holder behind.
  * **Fixed Mage Cloud MCP tool contracts:** align Mage Cloud MCP mutation payloads with Cloud Backend resource-root envelopes (`team`, `user`, `team_membership`, `invitation`) remove unsupported `cloud_users.create` from the advertised Cloud tool contract require.
  * **Fixed Mage Agent release packaging deps:** Fixes the Mage Agent macOS release packaging workflow so contract generation runs in a prepared Python environment instead of relying on ambient runner packages.
  * **Fixed Mage agent contract injection without config:** let `scripts/inject-mage-tool-contracts.py` fall back to static contract injection when dynamic MCP schema loading cannot build tools because Mage agent config is missing keep the existing missing-`requests` fallback int.
  * **Fixed data exporter graph icon contrast:** Fixes the data exporter icon contrast in the non-beta pipeline graph by removing the exporter-only `inverted` icon prop in `DependencyGraph/BlockNode`.
  * **Fixed base path index sign-in redirects:** Fix `getDomainAndPath()` so base-path index URLs do not become their own `redirect_url`.
  * **Fixed dynamic child reduce output graph tags:** Fix `Block.tags()` so `dynamic_child` is added through the existing reduce-output-aware dynamic child helper.
  * **Fixed pipeline widget graph arrows:** Fix the MCP resource widget pipeline graph so dependency arrows are drawn from the source block row to the target block card instead of floating between rows.
  * **Fixed duplicated base-path sign-in redirects from index URLs:** Prevent base-path index URLs from being reused as their own sign-in redirect target.
  * **Fixed pipelines filter request query:** Restores ToggleMenu behavior so unapplied filter drafts remain available after the menu closes.
