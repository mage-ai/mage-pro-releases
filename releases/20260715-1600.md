# Mage Pro Release Notes

**Release ID:** 20260715-1600  
**Release Date:** 2026-07-15  
**Python Version:** 3.12

---

## Highlights

- Major improvements to pipeline template management, discovery, and creation workflows
- Multi-factor authentication (MFA) setup and sign-in now available
- Enhanced release note preview rendering

---

## New capabilities

### Multi-Factor Authentication (MFA)

- **MFA Setup and Sign-In Requirements:**  
  Users and admins can now enable Multi-Factor Authentication for enhanced account security.  
  - Dedicated MFA device setup and verification flows now available in the user interface
  - Option to require MFA at sign in
  - Users see clear status and guidance throughout the setup and verification process  
- **MFA Policy and Lockouts:**  
  Improved feedback for failed attempts and lockouts to help users recover access.

---

## Improvements

### Pipeline Templates Experience

- **Browse and Discover Templates Easily:**  
  New and improved Pipeline Templates modal and navigation for streamlined browsing, search, and category filtering across both built-in and custom templates.
- **Custom Templates & Naming:**  
  Create pipelines from custom team templates and assign user-defined pipeline names.
- **Template Detail and Configuration:**  
  Refreshed forms, consistent layouts, scrollable template lists, and easier detail viewing for each template.
- **Name Collision Handling:**  
  Safer handling of pipeline creation from templates—users receive clear guidance and options when a name conflict occurs (e.g., overwrite, keep existing, or create with a new name).
- **Template Assets & Team Branding:**  
  Clear labeling and visual differentiation for custom/team templates, including updated icons.
- **Settings and Forms Polish:**  
  Improved template form spacing, validation, action button states, breadcrumb navigation, and visual clarity in template-related UI.
- **Category Navigation:**  
  Reordered and relabeled categories for better discovery, with flexible category controls and sensible defaults.

### Release Note Previews

- **Markdown Rendering for Release Notes:**  
  Highlights in release note previews are now rendered with full Markdown support for improved readability.

---

## Fixes

- Addressed bug where form state or button actions could become stale or ambiguous during template or pipeline creation.
- Resolved issues with template asset paths in modals and portals, ensuring correct display of icons and images.
- Fixed several minor UI polish and navigation state inconsistencies in templates and pipeline creation modals.
- Improved error handling and validation feedback during pipeline template creation and conflict resolution.
- MFA-related UI: Improved display of MFA completion states and handling of verification and lockout flows.
